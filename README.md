# cleanmydev-releases

Public release artifacts for [CleanMyDev](https://github.com/SaadBelfqih/cleanmydev).

Hosts:

- `appcast.xml` — Sparkle feed consumed by the in-app updater
- `release_notes.html` — rendered from `CHANGELOG.md` per release
- DMG downloads — attached to the GitHub Releases on this repo

Appcast URL: <https://saadbelfqih.github.io/cleanmydev-releases/appcast.xml>

Releases are cut by `scripts/release.sh` in the private source repo.
